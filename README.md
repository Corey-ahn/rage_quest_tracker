## 무엇을 보여 주나

작은 창에 쪽(페이지)별로 보여 줍니다. 제목줄의 `<` `>` 로 쪽을 넘깁니다.

- **일일 퀘스트** — 전장의 안개 · 징조의 틈 · 고래 노래만 · 바다의 촛대 · 공허 침략 · 원더랜드 악몽 · 황금 평원 · 정원 · 이프니르 · 매머투스 + 하라린트 · 영지
- **생활** — 푸른 소금 20 / 60 · 누이 여신 · 주민 · 행운 주화
- **주간 퀘스트** — 1단계 · 서부 / 동부 히라마 · 대초원 + 이프니르
- **기타** — 레이나·글렌·샤크라 · 정화(동/서) · 설원 보스 · 아켄 · 심연의 습격 · 나차쉬 · 신수 쟁탈전
- **별의별일** — 오늘의 과제 7칸. 특산품 과제는 펼치면 재료가 나오고, 재료를 두 번 클릭하면 경매장 검색
- **캐릭터 정보** — 왕 석상 축복 · 의상 / 속옷 / 다루 의상 기간 · 별의별일 · 원정대 과제 열림
- **오늘 번 것** — 경험치 · 골드 · 생활 점수 · 명예 (하루마다 0 부터)
- **인던** — 인던 15개의 오늘 입장 횟수. 두 번 클릭하면 인스턴스 팀 모집

글자 색: 빨강 = 안 함 · 주황 = 진행 중 · 초록 = 완료

## 원본에서 바꾼 것

### 한글화
- 애드온의 모든 문구를 한국어로 옮겼습니다.
- 줄임말은 게임 한국어 이름에 맞췄습니다 (예: GR → 전장의 안개, CR → 징조의 틈, Aegis → 바다의 촛대, Squad → 팀, 오늘의 과제 → 별의별일).
- 원본은 일부 기능을 **중국어 퀘스트 제목**으로 판정했습니다. 한국어 제목도 판정하게 했습니다.
  - 전장의 안개의 물자 부족 퀘스트 5종(석재·목재·옷감·가죽·철 주괴)을 "물자 부족" 한 줄로 합치기
  - 특산품 과제의 앞머리 `[특산품 - 서부]` 떼기 (재료 펼치기는 한국어 제목으로도 그대로 됩니다)

### 고친 것 · 더한 것
- **ESC 메뉴 [숙제체크] 버튼** — 다른 애드온처럼 ESC 설정창 옆 버튼으로 작은 창을 켜고 끕니다. 접속해도 기억합니다.
- **접기 버튼** — 제목줄 `[▲]` / `[▼]` 로 작은 창을 접고 폅니다 (마우스를 올리면 보입니다). 접속해도 기억합니다.
- **영지 고르기** — 원본은 영지가 한 곳(안식의 땅)뿐이었습니다. 영지 일일 퀘스트는 영지마다 따로라서
  살피마리 · 누이마리 · 서녘마리 · 안식의 땅 넷으로 나눴습니다. **처음엔 꺼져 있으니** 설정에서 점령한 영지만 체크하세요.
- **인던 저승의 밤** — 원본 목록에서 빠져 있던 것을 넣었습니다 (14개 → 15개).
- **창 위치** — 창을 옮기면 놓은 자리에 있지 않고 직전 위치로 되돌아가거나, 화면 배율에 따라 밀리던 문제를 고쳤습니다.
- **창을 숨겨도 갱신** — 원본은 작은 창이 숨으면 퀘스트 갱신 같은 예약 작업도 멈췄습니다. 숨겨도 돌게 했습니다.
- **안 보이던 글자** — 설정 창·확인 창은 바탕이 밝은데 글자가 흰색·회색이라 안 보였습니다. 진한 색으로 바꿨습니다.
- **인스턴스 팀 확인 창** — 무엇을 하는지 설명을 붙였습니다 (혼자 갈 수 있으면 빠른 매칭, 아니면 비공개 모집 팀).
- 접속할 때 나오던 개발자용 위치 진단 채팅을 껐습니다.
- 배포본은 주석을 뺐습니다 (동작은 같습니다).

## 설치

1. [Releases](https://github.com/Corey-ahn/rage_quest_tracker/releases) 에서 `questtracker-버전.zip` 을 받습니다.
2. 압축을 풀면 `infotracker2` 와 `globals` 폴더가 나옵니다. 두 폴더를 그대로 `문서\ArcheRage\Addon\` 에 넣습니다.
   ```
   문서\ArcheRage\Addon\infotracker2\toc.g
   문서\ArcheRage\Addon\globals\button.lua
   ```
   - ⚠️ 알집·반디집의 "압축파일 이름으로 폴더 만들기" 로 풀면 폴더가 한 겹 더 생겨 안 됩니다. **"여기에 풀기"** 로 푸세요.
   - `globals` 는 ESC 버튼에 씁니다. 다른 애드온이 이미 `globals` 를 쓰고 있어도 같이 둬도 됩니다.
   - 원본 infotracker2 를 쓰고 있었다면 같은 폴더라 덮어쓰면 됩니다 (설정은 그대로 남습니다).
3. 게임에 접속합니다. (이미 접속해 있었다면 재접속하세요. `/reloadui` 로는 반영되지 않습니다)

## 쓰는 법

- **창 옮기기**: `Shift` 를 누른 채 제목줄을 끌기
- **쪽 넘기기**: 제목줄에 마우스를 올리면 나오는 `<` `>`, 또는 제목을 클릭해 쪽 고르기
- **접기**: 제목줄 `[▲]` / `[▼]`
- **설정**: 제목줄 톱니 — 볼 항목 체크, 순서, 창 크기·글자 크기·투명도
- **켜기 / 끄기**: ESC 설정창 옆 `[숙제체크]`
- 퀘스트 이름·인던 이름·별의별일 문구는 게임이 주는 글자 그대로 나옵니다.
